# Food Delivery Data Analysis & Business Intelligence

A data analytics and business intelligence project that explores food delivery data using Python, SQL, and Power BI to uncover meaningful business insights and support data-driven decision-making.

## Project Overview

This project focuses on analyzing food delivery data to understand sales performance, customer behavior, and restaurant performance.

The project combines Python-based data analysis, SQL queries, and Power BI visualization to transform raw data into useful business insights.

## Project Objectives

- Explore and understand the food delivery dataset.
- Perform data cleaning and exploratory data analysis (EDA).
- Analyze sales trends and customer behavior.
- Use SQL to answer business-related questions.
- Develop interactive Power BI visualizations.
- Present analytical findings in a clear and understandable format.

## Tools & Technologies

| Tool | Purpose |
|---|---|
| Python | Data analysis and data processing |
| Pandas | Data manipulation and analysis |
| Jupyter Notebook | Writing and executing Python code |
| SQL | Querying and analyzing structured data |
| Power BI | Data visualization and business intelligence |

## Project Workflow

1. **Data Collection:** Load the raw food delivery dataset.
2. **Data Cleaning:** Inspect the dataset and prepare the data for analysis.
3. **Exploratory Data Analysis:** Explore the data to understand patterns, distributions, and relationships.
4. **SQL Analysis:** Use SQL queries to investigate business-related questions.
5. **Data Visualization:** Create visualizations and a Power BI dashboard to communicate insights.
6. **Business Intelligence:** Interpret the analysis to support data-driven business decisions.

### Files Description

- `food_delivery_sql_file.sql` – SQL queries used for data analysis.
- `power bi original.pbix` – Power BI dashboard file.
- `README.md` – Project documentation.

## How to Explore the Project

### 1. Clone the Repository

```bash
git clone https://github.com/ibraheem-cell/Food-Delivery-Data-Analysis-Business-Intelligence-.git
```

### 2. Navigate to the Project Folder

```bash
cd Food-Delivery-Data-Analysis-Business-Intelligence-
```

### 3. Explore the Python Analysis

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `food_delivery_raw.ipynb` to explore the Python analysis.

### 4. Explore the SQL Analysis

Open `food_delivery_sql_file.sql` in a SQL editor or database environment that supports the queries.

### 5. Explore the Power BI Dashboard

Open `power bi original.pbix` using Microsoft Power BI Desktop to explore the dashboard and visualizations.
